# 対戦表づくり（taisen-hyo）

架空の町の大会の運営係になって、人数・台の数などの条件から、試合の数・回戦の数・時間内に終わる方式・シードの置き場所を考える1日5問の学習ゲーム。計算の問題に正解したら「なぜその数になる？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/taisen-hyo/>

- 試合の数は計算で出します（勝ち抜き戦は人数−1、総当たりは人数×(人数−1)÷2、2回負けたら終わりは2×(人数−1)か、それに＋1）。
- スイス方式と総当たりの表（ベルガー表）の決まりは、FIDE Handbook の C.04.1 <https://handbook.fide.com/chapter/C0401202507> と C.05 Annex 1 <https://handbook.fide.com/chapter/C05Annex1> に書いてあることだけです。
- 出てくる町・大会・選手は練習のための架空のもので、本物の大会ではありません。お金・賭けは出てきません。
- ずんだもん解説「トーナメントは何試合」（YouTube 小江戸ゲーム部）と合わせて、自分で数えて確かめられます。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。結果の「共有」を押したときだけ、その日の回の番号と各問の○×の並びが、選んだサービス（X・LINE など）に渡ります。
